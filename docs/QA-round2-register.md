## Top 5 to fix before the pitch

1. **[P0] Provenance "Representative conservative" receipt is logically impossible** — FINPIPE Q 2024-12-31 shows real filing date **2024-01-18**, i.e. ~11 months *before* the quarter even ended. Back-end confirms **15 corrupt rows** in `provenance_knowable` (all Dec-quarters, off-by-one-year), and the example-picker selects the *worst* of them as the headline proof on the trust beat. (`fundamentals_filing_dates.py` + `provenance.py:1034`)
2. **[P1] CCI deterioration timeline emits false "guidance_walkback" red flags (★ deterministic = ranked)** — compares mismatched units inside one `statement_type` bucket: RELIANCE "revenue target lowered 114000→2", CGPOWER "1.5e+07→65000", "5e+07→400", "15→1.5". Raw scientific notation shown. A code comment in `concall_diff.py:26` admits the bug exists; the fix is incomplete (buckets by type, never by unit). These feed the credibility *rank*. (`concall_diff.py:48-67`)
3. **[P1] CCI promise-ledger Δ compares segment promises to consolidated actuals** — "Campa & Independence cross ₹1000cr" → Δ **+26038.8**; "JioStar ₹9,497cr" → Δ +2465; "Reliance Retail EBITDA ₹25,000cr" → Δ +1076. The settle engine divides a subsidiary target into the *group* revenue/EBITDA line, so both the Δ and the MET/MISSED verdict are unreliable for any segment-level guidance. (`concall_settle.py:118-119`)
4. **[P1] "HERMES" internal codename leaks on the client-facing Replay page** — `<h1>HERMES · REPLAY THE TAPE</h1>` and "**Hermes-rule** exit captured +172%". Product is "Patearn"; "Hermes" is the internal agent name only. On a flagship demo beat. (`scripts/build_dossier_html.py:207,315`)
5. **[P1] Pat conjunctive refine silently drops the base filter** — "strongest stocks … **with credible management**" returns pure credibility leaders (HDFCBANK, **SADBHAV**, IDBI, SUNPHARMA…), only **1 of 80** overlapping the RS-leaders it was refining. The conversational drill-down (the trust differentiator) does replacement, not intersection. (`src/pat/threads.py`)

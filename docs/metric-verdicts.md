> *Improve:* line describes what would change the READ — never a promise of returns. Verdicts
> cite `docs/strategy-ledger.md` / `docs/strategies/`.

- **DVPT.** *Plain:* Delivery size *Verdict:* Descriptive-only. The engine is live; the stock-picking thesis was tested and refuted — delivery-surge calibration failed out-of-sample in both directions, 2012–26 (only trade-size passed, δ+0.33). *Improve:* The read strengthens when intensity (×Power) rises while price holds its key-price band — it describes where committed money transacted, it does not predict. *Origin:* 🧑 Ramana concept, 🏠 house-built.
- **intensity.** *Plain:* Intensity (vs own history) *Verdict:* Descriptive sub-metric of DVPT, computed on read; never separately return-tested. *Improve:* Reads stronger as it climbs above 1× — always against the stock's OWN 1–12-month history, never the market's; on an illiquid name a spike is noise, so check median traded value first. *Origin:* 🧑 Ramana concept, 🏠 house-built.
- **Key price.** *Plain:* Where big money bought *Verdict:* Descriptive sub-metric of DVPT (value-weighted price of the power days); never separately return-tested. *Improve:* The read sharpens when several horizons (1M/3M/6M/12M) agree and price sits inside the −1%…+5% band of that level — it says where money transacted, not what happens next. *Origin:* 🧑 Ramana concept, 🏠 house-built.
- **mep_score.** *Plain:* Accumulation / Distribution *Verdict:* Descriptor-only (D62). Tested as an alpha source and failed the gate — deflated ratio 0.45→0.36 when added; recorded "do not re-test as alpha". *Improve:* A sign flip against the stock's own norm is the event worth noticing; the score contextualises the tape, it does not rank stocks. *Origin:* 🧑 Ramana concept, 🏠 house-built.
- **rs_band_pct.** *Plain:* Strength vs own range *Verdict:* Descriptive lens (RS suite); never return-tested as alpha. *Improve:* Read WITH the regime — "cheap" (a low band) on a de-rating trend is a trap, not a bargain; the read firms when the band turns up from under 20 with the rotation phase confirming. *Origin:* 📚 classic RS base, 🏠 house measurement.
- **composite_score.** *Plain:* Management credibility *Verdict:* Falsified as a return factor (leak-free residual-alpha Gate B FAIL; content axis placebo-killed: observed +1.90% vs null p95 +3.66%). Lives on as a veto/context layer only — never a ranker. *Improve:* The tier moves only as new concall promises settle true or break — it improves slowly by design; a forensic veto caps it regardless of score. *Origin:* 🏠 house-built.
- **Conviction.** *Plain:* Composite rank *Verdict:* Unproven heuristic — a sorting default blending positioning strength and RS rank; it has never been backtested and is not a validated model. *Improve:* Treat the ordering as a shortlist and check the underlying pillars the card links to; agreement across pillars is the read, the single number is not. *Origin:* 🏠 house-built.
- **ns_base.** *Plain:* Quality score (14 patterns) *Verdict:* Deployed filter/veto — never a ranker (D66): quality standalone showed ~0.0% alpha and failed both walk-forward halves. Financials are labeled not-applicable. *Improve:* The score firms as patterns move from unverified (×0.70 haircut) to verified with fresh filings — it filters durability, it does not rank returns. *Origin:* 🏠 house-built.
- **CPR.** *Plain:* Pivot structure *Verdict:* Descriptive charting lens (📚 classic pivot arithmetic on split-adjusted prices); shown for structure context, no directional claim. *Improve:* Narrow bands mark compression and widening bands mark expansion — the read is about levels and ranges, never direction. *Origin:* 📚 classic, 🏠 house measurement.
- **rs_rank.** *Plain:* Strength rank *Verdict:* Descriptive cross-sectional percentile (1–99, blend 0.6·3m + 0.4·6m RS slope); the RS suite was never return-tested as alpha. *Improve:* The read firms when the rank HOLDS a band across weeks rather than spiking into it — a stable top-quartile rank is the pattern the momentum literature measures, and momentum is a gross lens here, not a net edge. *Origin:* 📚 classic RS base, 🏠 house measurement.
- **pct_from_52w_high.** *Plain:* Distance from 52-week high *Verdict:* Descriptive context column — no directional claim; recorded here because base proximity to highs is a common conditioning variable in the momentum family (gross lens only). *Improve:* Read WITH strength and structure: near the high with top-quartile RS describes persistence; near the high on fading RS describes divergence. It locates price, it does not predict it. *Origin:* 📚 classic context, 🏠 house measurement.
- **return/vol.** *Plain:* Return ÷ volatility *Verdict:* The honest label (D142): every such ratio on this site subtracts no risk-free rate, so it reads ~1.7× a textbook Sharpe; relative comparisons hold exactly, absolute levels read high. A gate keeps the word "Sharpe" out. *Improve:* Compare ratios only against each other on this site (same construction both sides); against outside numbers, remember the missing risk-free subtraction. *Origin:* 📚 classic ratio, 🏠 house labeling rule.

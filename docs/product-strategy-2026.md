# Patearn — Product Strategy & PO Assessment (2026-06-24)

> Owner-as-PO assessment. Synthesis of 4 work-streams: B2B/institutional market research, niche/visual product research, UX-decisions research, and a full internal UI audit. ## 1. Verdict & wedge
The platform is signal-rich but built/shown like a tool aimed at no one. To be profitable + B2B:
- **Wedge (lead with this):** the only thing nobody sells for India — a **management-credibility time-series (CCI) that front-runs re-ratings**, on **point-in-time-honest** data, **fused with participant-flow.** Sell "trust + flow intelligence for Indian mid/small-caps, with audit-grade provenance."
- **Buyer:** PMS / AIFs / family offices / HNI advisors (PMS AUM ₹41.6 lakh cr; AIF >25% CAGR; HNIs+FOs = 80–90% of flows). NOT retail.
- **Two buyers, two budgets, one product:** PM buys the pre-re-rating shortlist (alpha); compliance officer buys the PIT audit trail (defensibility).
- **Academic tailwind:** analysts under-react to guidance → management credibility is under-priced (the alpha is real).

## 2. The 3 moats
1. **CCI compounds** every quarter; cannot be backfilled by a new entrant.
2. **PIT "replay the tape" honesty** → a compliance/audit revenue line incumbents can't match (Daloopa charges for provenance; we have it native).
3. **The fusion** (trust × flow × value) is orthogonal alpha, not repackaged momentum.
Avoid competing on breadth (Bloomberg/FactSet win) or price-charting (Koyfin/Trendlyne win).

## 3. Monetization ladder
Anchor seat (CCI Credibility Terminal) → expand (Smart-Money Tape, factor screener) → **data-feed/API** (highest margin, deepest lock-in; LLM/MCP endpoint) → **white-label PMS reporting** (per-AUM, stickiest). Plus a **compliance/audit tier** (PIT provenance vault).

## 4. The three decisions
- **Pat — NO separate tab.** Global layer: `Cmd-K` everywhere (primary, doubles as fuzzy nav + recovery hatch) + a slim docked "Ask Pat" bar → right-side panel (secondary). Carries the current screen's context server-side ("you're on RELIANCE · RS-Band 12m"). Retire `/dash/pat` as home; keep URL as fallback transcript. *Pat is a layer you summon, not a place you go.*
- **Themes — keep the multi-label DATA model (it's right + a moat); fix the POSITIONING.** Demote "Themes" from a top-nav destination to a pervasive **scoping filter** (chip in Screener/Markets/lists); re-package a **small curated set as conviction-backed "Baskets/Exposures"** named by mechanism, selected by the lenses, shown *through every lens at once*. Sell the edge, scope with the theme.
- **Help/onboarding — NO guided tour.** Cmd-K = recovery hatch; persistent "?" / "Ask Pat" handle; **`ⓘ` glossary in context at each lens** (wire the built `glossary.py`); teaching empty states; home = a map of altitude cards. Teach lenses where used, then get out of the way.

## 5. Chart geometry (the complaint, diagnosed)
`src/web/stock_chart.py`: height hard-coded 480px (JS overrides HTML 300px); **ResizeObserver watches width only** → grows wide, never tall ("narrow top, broad sides"); **`scaleMargins.bottom:0.28`** gives 28% of height to the flow lane → price plot ~345px; Y-axis auto-narrow. **Enlarging won't work today** (height is a constant the observer ignores). **Fix (= §6 P3):** `height:clamp(420px,62vh,760px)` + `max-width~1200`; observe width AND height → `applyOptions({width,height})`; `⤢` fullscreen; **flow/volume/DVPT become their own stacked panes on one synced x-axis** (price keeps full height). Apply one bounded chart-host to ALL charts (today: stock=480, ratio/compare=320, RRG/band SVGs 100%-width-fixed-height = 4 rules).

## 6. UI consistency (12 audit findings → 1 cause)
No shared design system; each screen invented its own controls. Worst: 3 "active" styles (fbtn pill / subnav underline / chart chip); color clash (Rotation uses blue=bullish/amber=bearish vs green/red elsewhere); benchmark toggles default oppositely (rrg `sector` / rsband `broad`); uneven frozen-pane (Screener yes, Tracker no); 4 chart-sizing rules. **Fix:** extract a small design system — one toggle, one frozen-pane table, one chart host, one color contract, one benchmark default. Additive; sacred routes keep URLs.
